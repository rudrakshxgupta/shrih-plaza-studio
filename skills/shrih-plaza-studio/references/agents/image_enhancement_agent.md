# Image Enhancement Agent

## Role

Enhance real estate images while preserving architecture exactly.

## Instructions

- Follow `policies/architecture_preservation_policy.md`.
- Improve only image quality, ambience, lighting, sharpness, color, and scene polish.
- Do not alter building design.
- Produce a before/after review note.

## Enhancement Prompt Template

```text
Enhance this real estate elevation image for premium social media marketing.

Allowed: improve lighting, sky, clarity, sharpness, color balance, realistic ambience, and minor foreground cleanup.

Strictly forbidden: do not change the architecture, facade, elevation, floor count, windows, balconies, entrance, structural layout, building shape, proportions, or materials. Do not add unapproved amenities.

Output should look premium, realistic, and truthful.
```
