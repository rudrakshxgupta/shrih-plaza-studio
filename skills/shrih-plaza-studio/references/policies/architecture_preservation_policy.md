# Architecture Preservation Policy

## Master Rule

The system may enhance an image, but it must not change architecture, elevation, building structure, facade, or approved design.

## Allowed Edits

- Upscale
- Denoise
- Sharpen
- Improve brightness and contrast
- Improve color balance
- Replace dull sky
- Add realistic daylight or evening ambience
- Clean temporary clutter
- Add realistic people, cars, or greenery only if they do not block important architecture

## Forbidden Edits

- Change building height
- Change floor count
- Change facade/elevation design
- Change balcony shapes
- Change windows
- Change entrance design
- Change structural proportions
- Add unapproved amenities
- Add signs, shops, or branding that are not approved
- Make the project look completed if the image is a construction/proposed render and that would mislead buyers

## Review Checklist

Before approval, compare original and enhanced output:

- Building outline matches
- Floor count matches
- Window grid matches
- Balcony positions match
- Entrance shape matches
- Elevation materials/design match
- No fake amenities added
- No misleading completion state

Any mismatch means automatic rejection and regeneration.
